3.2. Displaying Temperature on the LCD Screen#

In this lab, you will learn about the basics of the SSD1306 LCD screen and how to display the data from the temperature sensor from the Pico to the LCD screen.

3.2.1. Materials#

  • USB cable

  • Breadboard

  • Raspberry Pi Pico

  • LCD screen

  • Wires

3.2.2. Getting Started#

Note: might have to add something about getting the ssd1306.py file downloaded from somewhere.

  • Open VSCode, and open your Phyical-Computing project.

  • Open your lab3 file and create a main.py file where you will write your code for this lab.

3.2.3. Hardware#

Step 1: Connect the LCD display to the breadboard#

Place the LCD display on the breadboard so that its pins align with four consecutive rows. Ensure that all the pins are inserted securely into the breadboard.

(insert photo/ fritzing diagram)

Step 1: Locate the Pins#

Locate the 4 pins on your LCD screen. They should be labeled as follows:

  • VCC: 3.3V (if needed, refer to previous labs on how to connect)

  • GND: Ground (if needed, refer to previous labs on how to connect)

  • SDA: Serial Data Line

  • SCL: Serial Clock Line

Step 2: Connect VCC and Ground#

  • Connect the row where VCC is placed on the LCD screen to the 3.3V pin on the Pico using a wire.

  • Connect the row where GND is placed on the LCD screen to a GND pin on the Pico using a wire.

(insert photo/ fritzing diagram)

Step 3: Connect the Data Pins#

This example uses ground pin 16 for SDA and ground pin 17 for SCL, but you may choose any pair of SDA and SCL pins on the pico. Refer to the GPIO Pin diagram for where the SCL and SDA pins are located.

  • Connect the row where the SDA pin is placed on the LCD screen to GP16 on the Pico using a wire.

  • Connect the row where the SCL pin is placed on the LCD screen to GP17 on the Pico using a wire.

(insert photo/fritzing diagram)

Step 4: Connect the Raspberry Pi Pico to Your Computer#

Connect your Raspberry Pi Pico to your computer using the USB cable provided in your lab kit. While plugging in the device, hold down the BOOTSEL button. Drag and drop the MicroPython UF2 file into the device folder of the Pico.

Now everything should be connected, so let’s move on to the coding portion.

3.2.4. Code#

Step 1: Adding nescessary imports#

Import the machine and time libraries. The ADC and Pin modules should be familiar from previous labs.

from machine import ADC, I2C, Pin
from ssd1306 import SSD1306_I2C
import time

The I2C module allows us to establish I2C communication from our pico.

The SSD1306_I2C class allows us to interact with the LCD screen without having to deal with memory addresses or memory management. The SSD1306_I2Cclass is built on top of the SSD1306 class, which handles most of the application logic for interacting with the screen like turning it on and off. The two functions defined within the SSD1306_I2Cclass are

write_cmd: sends a command to the screen

write_data: writes data from the buffer to the screen. This is how stuff gets displayed on the screen.

Step 2: Initalize I2C Communication#

Initialize an I2C object called i2c with the following constructor:

i2c = I2C(0, scl=Pin(17), sda=Pin(16), freq=400000)

Parameters:

  • id: identifies a particular I2C peripheral. Allowed values for depend on the particular port/board

  • scl: a pin object specifying the pin to use for SCL.

  • sda: a pin object specifying the pin to use for SDA.

  • freq: an integer which sets the maximum frequency for SCL.

Note: change the pin numbers to the SDA and SCL pins you are using if your wiring was different.

Step 3: Initalize the LCD Screen#

Now you’re going to create a variable called oled which is an instance of SSD1306_I2C class from the ssd1306.py by doing:

oled = SSD1306_I2C(width, height, i2c)

Parameters:

  • width: The width of the display in pixels (128 for this screen).

  • height: The height of the display in pixels (64 for this screen).

  • i2c: The I2C object you initialized in the previous step.

Step 4: Reusing the Temperature Sensing Function#

Next, we want to reuse the get_temperature() function from Lab3 Project 1 that returns the reading of the temperature sensor on the Pico. We will be calling this function to display the temperature sensor data on the LCD screen.

Step 5: Displaying the Temperature#

oled.fill(0)

  1. Display the label “Temperature:” using the oled.text method:

Step 6: Running the Program#

In VSCode, locate the Run button in the bottom taskbar and click Run to execute the code on your Raspberry Pi Pico. You can stop or reset the program at anytime using the controls in the bottom taskbar or by pressing CTRL+C on your computer (CMD+C on Mac).
