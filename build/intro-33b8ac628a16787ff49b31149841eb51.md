
# **Physical Computing**

Purdue College of Engineering is offering this course on Physical Computing to anyone
who has passed the Entry-Level Programming in Python course or has a moderate amount
of experience in Python programming.

This course is designed to take what you know about programming and apply it to the
physical world. You will learn how to use MicroPython to interact with hardware and see
the real world effects of software that you write.
