1.2.3. Stop Light Project#

With the past few projects and labs, you have learned about general bread boarding concepts, LEDs, switches, buttons, and more. Now, it is time for you to use that knowledge to create this stoplight project with limited guidance.

Please keep in mind that if you need help or have questions, you will have TAs available to help you with your concerns.

Project Description#

Utilizing previous concepts taught during the course, you will be creating a simulated version of a spotlight. The topics below are the things which you are trying to simulate with this project:

  • The stoplight itself that cycles through the colors red, yellow, and green

  • A button that will allow pedestrians to cross the street, lighting up a crossing light after the light turn red

  • A switch for spotlight maintenance, turning and keeping the light red

We have provided a general guide to approaching the creation of this project below but the ways in which you implement these parts of the stoplight will be up to you. Good luck and have fun!

Materials#

  • Four LEDs

    • One Red LED

    • One Green LED

    • One Yellow LED

    • One White LED

  • Four resistors

  • One button

  • One switch

  • Several wires (total amount is up to designer)

  • One breadboard

  • Raspberry Pi Pico

Hardware#

Step 1: Set up the LEDs#

These LEDs are going to mimic a stoplight. This means that each LED should turn on without any other LEDs lighting up at the same time. Additionally, since these lights are going to switch at different times, they need to be connected to different Pins of the Pico to light up individually and to control the time that they switch.

Make sure to have a resistor of the appropriate Ohm amount for each of the LEDs you attach. Have each LED connected to a different Pin of the Raspberry Pi Pico so that you are able to light up each LED individually.

Please note that the white LED will be controlled differently as it will only light up if the button has been pushed. This may change the way you plan to set up the board.

Step 2: Set up the switch#

The switch will be used to turn on the red LED and turn off all other LEDs, similar to a maintenance switch.

The switch should be connected to two different Pins of the Pico, one that is for outputting voltage and the other for intaking voltage to tell that the switch has been flipped and we want to keep the light red on.

Step 3: Set up the button#

We are going to use the button as a crosswalk button, where pushing the button will eventually turn on the white LED. As such, we need to know if the button has been pushed or not.

To set this up, ensure the button is connected to two Pins of the Pico, one for outputting voltage, and the other for intaking voltage to see if the button has been pushed, similar to the setup of the switch.

Code#

You’ve finished the hardware set up so let’s move onto code.

We will once again be using the sleep function in order to have the LEDs change after a certain amount of time. Keep in mind that using the sleep function will mean that our code no longer runs while the code is sleeping. This means that the value we set inside the sleep function should be smaller than 1 second so that pushing the button or changing the switch will register without significant delay.

Step 1: Set up all variables for the code#

Each of the different things on the board: the four LEDs, the switch, and the button, will all have at least one corresponding Pin that needs a variable, either to send voltage through the object or to read voltage from the object.

Some additional variables that we want to set up are thus: a variable to keep track of how long our LEDs have been lit up, one for the regular traffic light LEDs (red, yellow, and green) and one for the white LED.

Step 2: Setting up the rest of the program#

Since we are expecting this code to loop, we will create a while loop so that we can see our LEDs cycling through all the different colors. We will do the rest of the coding inside of this while loop

Step 3: Code for our switch#

As mentioned before, we want to check if the switch has voltage flowing into the Pin we have designated as the Pin keeping track of the voltage input of the switch.

If we find that the switch has allowed voltage into this Pin, we want to turn off all other LEDs and turn on the red LED

Step 3: Code for our button#

If the button is pushed, we want to set up the rest of the code so that the white LED will turn on after a final stop light cycle. There are multiple ways to do this, just ensure that the setup makes sense with the rest of your code.

Additionally, we want to ensure that if our button has been pushed already, and set up has been completed, we can continue running smoothly. Make sure that when you keep the button held down, the rest of the code still runs.

Step 4: Lighting up our LEDs#

Use the counter made during variable set up to keep track of when to change the LEDs. Make sure when lighting up one LED, you turn off all LEDs that would be on at the time of the switch.

When using the counter to keep track of the time that the LEDs are lit up, we need to ensure that the counter actually takes some amount of time before it is increased. We do this using the sleep function. Remember the warning that was listed earlier in regards to using the sleep function.

Keep in mind, you want to ensure that if the button has been pushed and the red LED has finished its cycle, we want to turn on the white LED. Also remember to reset the white LED’s associated variables so that the white LED doesn’t continuously turn on when you wish to turn the white LED off.

Step 5: Test your code#

Run your code and check that everything works as expected. This means that

  • The red, green, and yellow LEDs will cycle through each color continuously

    • It will go from green to yellow to red and then back to green

  • If the switch is changed, the red LED will continuously stay on until the switch is flipped back

    • This will happen regardless of if the button has been pushed or not or if the lights were on a different color than red when the light has been switched

  • If the button is pressed, the white LED will turn on after the red LED turns off

    • The button continuously being pressed should still allow the rest of the cycle to continue
