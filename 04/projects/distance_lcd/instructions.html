4.3.2. Distance Sensor Display#

Build a circuit that reads distance measurements from a VL53L0X sensor and prints them to the VS Code MicroPico vREPL in real time.

Introduction#

Many devices – robots, automatic doors, parking sensors – need to know how far away an object is. The VL53L0X uses a tiny infrared laser to measure distance by timing how long the laser pulse takes to bounce back. In this project you will wire the sensor to the Raspberry Pi Pico over the I2C bus and write MicroPython code that reads and displays the distance every 100 ms.

Reference: VL53L0X tutorial

Materials#

  • 1 breadboard

  • 1 Raspberry Pi Pico

  • 1 USB cable

  • 1 computer with VS Code and the MicroPico extension installed

  • 6 jumper wires

  • 1 VL53L0X distance sensor – a small blue rectangle with a circular lens. Look for the label “VL53L0X” on the board (the “V” may look like a “U”). The sensor has four pins: VIN, GND, SCL, and SDA.

Instructions#

Hardware#

Step 1: Mount the Pico#

Place the Raspberry Pi Pico on the breadboard so that each row of pins is on a separate side of the center gap.

Step 2: Mount the VL53L0X sensor#

Place the VL53L0X on the breadboard so that you can read the text on it when looking at the board straight on. One side of the sensor should be on the left rail and the other side on the right rail.

Step 3: Wire power and ground#

Connect the Pico 3.3 V pin to the VIN pin of the sensor. Connect a Pico GND pin to the GND pin of the sensor.

Step 4: Wire the I2C bus#

Connect Pico GP20 to the SDA pin of the sensor. Connect Pico GP21 to the SCL pin of the sensor.

Code#

Step 1: Add the VL53L0X library#

The VL53L0X driver is not included with MicroPython, so you need to copy it to the Pico manually.

  • Download the library file: vl53l0x.py

  • Connect your Pico to VS Code and open the MicroPico vREPL.

  • In the VS Code file explorer, right-click vl53l0x.py and choose Upload file to Pico.

Step 2: Write the imports#

Create a new file called main.py on the Pico and add the following imports:

import utime
from machine import Pin, I2C
from vl53l0x import VL53L0X

utime is the MicroPython time module. Pin and I2C come from the built-in machine module and let us control the hardware pins.

Step 3: Set up the I2C bus#

# SDA on GP20, SCL on GP21 -- matches the wiring from the Hardware steps
i2c = I2C(0, sda=Pin(20), scl=Pin(21))

The I2C constructor takes an id that selects the hardware peripheral (0), plus pin objects that tell it which GPIO lines to use for data and clock.

Step 4: Create the sensor object#

tof = VL53L0X(i2c)

Passing the i2c object lets the driver communicate with the sensor over the bus you just configured.

Step 5: Configure timing and range#

# 40000 us timing budget: slower reads but more accurate results
tof.set_measurement_timing_budget(40000)

# These VCSEL pulse-period values expand the usable measurement range
tof.set_Vcsel_pulse_period(tof.vcsel_period_type[0], 12)
tof.set_Vcsel_pulse_period(tof.vcsel_period_type[1], 8)

The timing budget controls how long the sensor spends on each measurement. The default is 0 (disabled), so setting it to 40000 microseconds enables full accuracy mode. The VCSEL (vertical-cavity surface-emitting laser) pulse periods tune the pre-range and final-range phases of the distance algorithm.

Step 6: Read distance in a loop#

while True:
    print(tof.ping(), "mm")
    utime.sleep_ms(100)

ping() triggers a single measurement and returns the distance in millimetres. The 100 ms sleep prevents flooding the console with readings.

Validation#

Run your code and hold your hand at different distances above the sensor. Confirm each of the following:

  • Numbers stream continuously in the MicroPico vREPL with “mm” appended.

  • Moving your hand closer produces smaller numbers; moving it further away produces larger numbers.

  • Readings are stable (not jumping wildly) when your hand is held still.

  • Removing your hand entirely causes the reading to jump to a large value (near the sensor’s maximum range, roughly 1200 mm).
