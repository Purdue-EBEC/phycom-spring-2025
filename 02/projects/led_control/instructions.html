2.2.1. Dimming with PMW#

Materials#

  • USB cable

  • Breadboard

  • Raspberry Pi Pico

  • Resistor (same resistor calculated in external LED lab)

  • LED (any color)

  • Potentiometer (3 prong)

  • Kit Wires

Objective#

First we will build a circuit that changes an LED’s output with an analog input from a potentiometer. Then we’ll remove the analog input and achieve the same effect by shaping the time it spends ON versus OFF (PWM). This gives you more control over your parts, allowing you to run them anywhere within their full operational range (from 1 to 0). We will observe how changing the Duty Cycle, Frequency, and Period effects the LED output. Hopefully you will be able to see PWM as a tool you can use by the end of this lab.

Part 1 - Analog Input#

Step 1: Circuit Setup (analog)#

First take a look at the pico’s GPIO pins choose an output pin. In the pictures we used GP15 on pin 20, but you dont have to. Then select a GND pin, since they all do the same thing you don’t need to select carefully. Wire that GND pin with a kit wire to one of the blue GND terminals that run along the side of your breadboard. Connecting both GND terminals is possible and easy, but not necessary for this lab.

Take the 3 pronged potentiometer, the blue component with a dial on top. Find the numbers that say 1 and 3, indicating which of the 3 pins are which. Place it with all three pins having their own rows, for example with pin 1 on row 25, 2 on row 26, and 3 on row 27. An example is shown below.

Use a wire from the kit to connect pin 1 of the potentiometer to the GND terminal we setup.

Take the long leg (anode) of the LED and connect it to pin 2 of the potentiometer. Have the short leg (cathode) connect to an empty row. Connect the LED cathode to the same resistor you calculated and used in Unit 1’s external LED lab. see Lab 1 instructions here. Place one end in the empty row from step 4. Then take the other end of the resistor and connect it to the GND terminal.

Take another wire from the kit and connect pin 3 of the potentiometer to the GPIO pin you chose earlier. This pin will act as our voltage source in step 1. And with that, we’re ready to add code.

Step 2: Code Setup (analog)#

Make a new main.py file. Add the necessary imports of

from machine import Pin
from utime import sleep

Set our selected GPIO pin to be an output voltage source, and then set that source to HIGH for 3.3V output. Make sure to Replace XX with the number of the GPIO pin you chose while breadboarding.

vsource = Pin(XX, Pin.OUT)
vsource.value(1)

Add a while loop to keep the pico on and running for the dimming circuit.

while True:
    sleep(1)

Step 3: Run the program (analog)#

  • Run the completed main.py file.

  • What happens when you turn the potentiometer’s knob all the way left? What about all the way right?

  • Towards which side of the potentiometer is there higher resistance values?

Part 2 - Pulse Width Modulation#

Step 1: Circuit Setup (PWM)#

Completely deconstruct the circuit we made for part 1. Leave the pico on the board of course, and the GND terminal connected.

Then setup a single external LED the same way as you did in Unit 1, with the same calculated resistor as Lab 1. The circuit is setup the same way we see in Unit 1: Blink External LED

Take your resistor and connect it to one of the GPIO pins. Any of the GPIO pins will work, just make sure it’s the same one you use in the code. Put the other leg of the resistor into an empty row. Take the long leg (anode) of the LED and connect it to the resistor in the empty row you chose. Connect the LED’s short leg (cathode) to any GND pin directly, or to the GND terminal like in part 1 of this lab. Then the circuit is complete.

Step 2: Code setup (PWM)#

  • Comment out all the code from part 1 in the main.py file. Add the necessary imports of

from machine import Pin, PWM
from utime import sleep

  • Set the GPIO pin you connected to and set the frequency to 1000Hz. Make sure to Replace ‘XX’ with the number of the GPIO pin you chose while breadboarding.

  • 1000Hz is chosen as the frequency because it is fast enough to create the illusion of a continuously lit LED, even though the LED is actually blinking.

led = PWM(Pin(XX))
led.freq(1000)

  • Add a control to the brightness by setting a value and calculating the Duty Cycle. Choose T_on as a value from 1-100, which we will use as the duty cycle.

  • Relating the “duty_value” back to the (2.1), the “100” in “(T_on / 100)” is (T_on + T_off), or 100% of one period. Tperiod is set to 100, so any integer chosen between 1-100 for T_on will also be the duty cycle for our lab.

  • The syntax “led.duty_u16” stores the duty cycle percentage as a register with a max value of 65535, which is why we multiply the duty cycle by 65535 before plugging it in.

T_on = 70  
duty_value = int((T_on / 100) * 65535)

led.duty_u16(duty_value)

  • Then add this while loop to keep the pico on and running for the dimming circuit.

while True:
    sleep(1)

  • With that the code is ready to run.

Step 3: Run the program (PWM)#

  • Run the completed main.py file.

  • What happens when you increase the duty cycle? When you decrease it?

  • What happens when you make the frequency around 60-100 Hz? What happens when it’s 500 Hz? Around what frequency do you see the LED blinking at?
